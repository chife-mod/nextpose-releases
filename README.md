# NextPose — Releases

Public release artifacts for **NextPose**, the desktop posture coach.

→ Latest: [nextpose.app](https://nextpose.app) · [Releases](https://github.com/chife-mod/nextpose-releases/releases)

## What is this repository?

This is the **public distribution mirror**. It contains:

- `.dmg` installers per release
- `.app.tar.gz` + `.sig` bundles for the auto-updater
- `latest.json` — endpoint consumed by the in-app updater

The NextPose app source is closed-source.
